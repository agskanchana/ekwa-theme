# EKWA Working Hours Block

Display location working hours with flexible formatting and grouping options.

## Features

- **Location Selection**: Choose which location's hours to display
- **Multiple Display Formats**: 
  - Standard list (each day separate)
  - Grouped by consecutive days with same hours
  - Grouped by any days with same hours (non-consecutive)
- **Show/Hide Closed Days**: Toggle visibility of closed days
- **Short Day Names**: Display abbreviated day names (Mon, Tue, etc.)
- **Customizable Styling**: Control text colors and layout

## ACF Fields

- **Location**: Select location (default: 1)
- **Show Closed Days**: Toggle to show/hide closed days
- **Short Day Format**: Toggle for abbreviated day names
- **Group Format**: 
  - `none`: Show each day separately
  - `consecutive`: Group consecutive days with same hours
  - `all`: Group any days with same hours
- **Text Color**: Main text color
- **Time Color**: Hours text color

## Usage

Add the block in Gutenberg editor and configure the settings in the block sidebar.
