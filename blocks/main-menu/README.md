# EKWA Main Menu Block

Responsive navigation menu with desktop dropdown and mobile mmenu support.

## Features

- **Desktop Mode**: Horizontal dropdown menu with hover states
- **Mobile Mode**: Slide-out mmenu for tablets and mobile
- **Breakpoint Control**: Customizable breakpoint (default: 1154px)
- **Per-Item Visibility**: Show/hide menu items on desktop or mobile
- **Icon Support**: Font Awesome icons for menu items
- **Two-Column Submenu**: Optional two-column layout for large submenus
- **Extensive Styling Options**: Colors, padding, spacing, etc.

## ACF Fields

### Desktop Styling
- Background color
- Text color
- Hover background/text colors
- Padding (X and Y)
- Gap between items
- Show dropdown icons

### Submenu Styling
- Background color
- Link background/text colors
- Hover states
- Width
- Separator color
- Two-column mode

### Responsive
- Breakpoint (default: 1154px)
- Mobile menu trigger button styles

## Menu Item Custom Fields

Add to each menu item:
- **Icon**: Font Awesome class (e.g., `home`, `phone`)
- **Visibility**: Desktop Only, Mobile Only, or Both

## Usage

1. Add block to header/navigation area
2. Configure styling in block settings
3. Add custom fields to menu items in Appearance → Menus
4. Menu automatically switches between desktop/mobile modes based on breakpoint
